# 生产排期交互原型

本地预览：http://127.0.0.1:5193/

这是独立的桌面交互原型，使用固定日期（2026-11-03）和示例数据。未接入业务接口，不会修改正式排期；刷新后恢复示例计划。

## 查看方式

- 看板左侧只保留流水号 / 班组与独立的数量列。交货任务、材质、最终交期、业务人员放在流水号详情中。
- 收起流水号时，以班组颜色概览完整加工时段；展开后展示该流水号在各班组的分批计划。
- 横条起止位置对应计划开始、计划转出，长度对应持续时间。并行批次分行，不能通过拉宽短任务来伪造时长。
- 在制批次用实色条，待加工用浅底描边，已转出用淡色和勾；深色进度表示已加工比例。班组名旁的实色数量标出物料当前位置，逾期增加红色标记。
- 单击批次高亮其明确关联的上下游，其他批次淡出；点击底部“查看详情”或双击横条打开批次详情。空白处、取消按钮或 Escape 取消选择。可修改时间、拖动未完成批次，支持撤销。
- 旗标表示最终交期，悬停、键盘聚焦或选中该流水号的批次时显示日期。单批班组行高 52 px，两批重叠为 88 px。
- 示例关联使用独立的物料流转 links；批次号相同不会自动关联。正式接入需由实际拆分、合并、转出关系提供 links。
- 时间按钮打开双月日历，支持自选范围、周 / 双周 / 月、前后翻页。支持筛选、搜索、全屏和 CSV 导出。

首个示例为 100 件分成 60 / 40 件两批：60 件在研磨、40 件在退火，用于验证同一流水号同时分布在多个班组的表达。

## 范围

这次验证布局与交互，不包含账号权限、真实物料追踪、班组排期写入、消息通知、批次新增 / 数量重分配、工艺和图纸接口。正式接入时应复用现有后端与权限，不以示例数据代替真实数据。当前界面优先验证桌面 1440 × 900 和 1280 × 800；手机端未作专项设计。

## 开发

使用 Node.js 20.19+ 或 22.12+。在本目录执行 `npm install`，再执行 `npm run dev -- --host 127.0.0.1 --port 5193 --strictPort`。当前会话已启动服务，用户无需重复启动。

`npm run build` 构建本地静态产物；没有执行发布或部署。
