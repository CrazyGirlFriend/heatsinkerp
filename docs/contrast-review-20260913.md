# 表头与班组页签对比度检查

2026-09-13，本地。范围为当前业务表格及班组工作台页签，不是全系统无障碍认证。用户目标是在密集记录中快速区分表头/正文，并明确当前所在页。

## 1. 查看台账及悬停另一个页签

调整前实拍：

![调整前：表头浅、选中与悬停均为紫色](../output/playwright/contrast-20260913/01-before-ledger-hover.png)

- 原有优点：表格按 20 条显示，页签有选中语义及键盘切换，数据与操作均保留。
- 层级问题：表头背景 #f4f6fb 与白色正文非常接近，表头文字 #53617a / 500 字重与正文 #59647b / 400 字重接近，横向扫读缺少明确起点。
- 状态问题：当前“流水号台账”和悬停“入库记录”都实际计算为 #6550ed，背景均透明；只有细下划线区分，易被误认为两个当前页面。
- 可访问性边界：原表头文字/背景计算对比约 5.78:1，因此问题不应简单描述为所有文字未达标准，主要是视觉层级与状态辨识弱。截图不能代替屏幕阅读器或色觉测试。

## 2. 调整后检查表头、页签与键盘切换

调整后同尺寸、同页、同悬停位置实拍：

![调整后：灰蓝表头与实色选中页签](../output/playwright/contrast-20260913/02-after-ledger-hover.png)

- 表头为灰蓝 #dfe5ef、深色 #253248、650 字重，下分割线 #bac6d9；正文 #344158、400 字重，保持白底和浅色斑马纹。主题覆盖普通业务表、管理表和详情表，明确排除 .live-table。
- 当前页签为紫底白字、600 字重；普通页签深灰，悬停为灰蓝底/深色文字，不再使用与选中相同的紫色。待接收数量保留独立徽标。
- 选中与键盘焦点仍分别表达：方向键切换后选中和焦点都转到“待接收”，页签仍有 aria-selected、tabindex 和面板关联；尊重减少动态效果设置。
- 实际计算颜色的对比值：表头文字/底色 10.19:1，正文/白底 10.28:1，选中页签白字/紫底 5.35:1，悬停页签文字/底色 12.28:1。这里只检查这些配色，不承诺所有组件、状态或显示设备符合完整无障碍标准。
- 当前判断：所指两处层级问题已改善，20 行页容量、查询及业务按钮未变。图标、字号体系、数据和大屏样式保持不变，不用新卡片增加信息层级。
