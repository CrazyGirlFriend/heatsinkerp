# 前端组件适配检查与修复

日期：2026-11-04。范围：当前 Vue 前端；全厂总览保留原样。此次不改变库存、共投、转投、排期等业务规则，也不重构为 React。

## 检查结论

主题颜色、边框和表格外观已有较广覆盖，但公共交互没有完成统一。Watermelon 是 React 参考实现，项目采用 Vue 适配；不能把全局 CSS 换肤等同于完整组件适配。

| 项目             | 检查时的情况                                           | 修复目标                                                           |
| ---------------- | ------------------------------------------------------ | ------------------------------------------------------------------ |
| 按钮             | AppButton 与 WatermelonButton 并存，按压和加载反馈不同 | 共用按压、加载、尺寸和可访问性规则，保留原生提交与焦点恢复         |
| 输入、下拉       | 多数仅全局换肤                                         | 统一输入状态与弹出层，保留搜索、多选、清空、远程加载               |
| 日期与时间       | 新日期组件只被发货日期字段引用，其他选择器各自实现     | 统一日历、日期时间、范围选择的主题与动画，不丢失禁选日期和业务约束 |
| 弹窗、抽屉、确认 | 多套入退场与按钮规则                                   | 统一动效参数与视觉，保留嵌套、焦点、Escape、关闭保护               |
| 页签、开关       | 新旧组件并存                                           | 统一选中反馈、内容切换、禁用与键盘行为                             |
| 表格、加载       | 行过渡被关闭，部分表格仅显示加载文字                   | 统一骨架、刷新提示及完成衔接；不逐行播放大规模入场动画             |
| 提示、校验       | 动画校验只覆盖部分表单，多数业务提示仍为默认组件       | 共用警告、错误、成功样式和入场；保留错误定位与持久提示             |
| 筛选、显示列     | 表头筛选、显示列、登记日期各自弹出                     | 共用弹出层和选项反馈                                               |
| 附件、空状态     | 上传多为文字，空状态沿用默认图片                       | 共用上传进度状态、成功/失败反馈、加载与空状态                      |
| 明确残留         | 登记日期选中项暗色主题白字浅底；重量单位为原生下拉     | 修正主题对比度；单位选择接入共享下拉                               |

## 验收要求

- 白天/夜间主题一致，尊重减少动态效果设置。
- 键盘选择、原生表单提交、loading/disabled、嵌套弹层焦点恢复仍有效。
- 日期时间、精度、单位换算、过滤、分页及服务端请求参数不变。
- 共享组件的行为回归测试、类型检查与生产构建通过。
- 使用单个 Chrome 自动化实例检查关键组合；结束后关闭本次创建的实例。

## 修复记录

已完成检查清单内的公共组件接入，回归验证结果在下节记录。

1. 按钮共用 `AppButton` 和 `useControlFeedback`。鼠标、键盘按下时有轻量反馈，加载时保留布局宽度和可访问名称，阻止重复点击。
2. 输入、下拉、联想输入、日期和浮层接入 `AppInput`、`AppSelect`、`AppAutocomplete`、`AppDatePicker`、`AppPopover`。原有多选、远程查询、禁用、清空、插槽和事件继续交给 Element Plus。业务代码未改为 React。
3. 日期单选增加选中反馈；日期范围保留原生起止和区间高亮，避免自定义日期单元格覆盖范围状态。390px 窄屏双月日历改为面板内纵向滚动。登记日期的暗色选中项改用主题前景色。
4. 页签、开关通过 `AppTabs`、`AppSwitch` 接入；保留离开拦截、开关校验和禁用状态。弹窗、抽屉与确认框共用动效参数，清理关闭按钮在悬停/键盘聚焦时遗留的玻璃背景和图标旋转。
5. 表格首次加载显示 `AppSkeleton`，刷新已有数据时保留行并显示顶部进度提示；加载完成仅做短暂淡入。`AppSkeleton` 保留文档自定义占位插槽。空结果与失败重试使用 `AppEmpty` / `StatePanel`。
6. 内联提示、全局消息和确认通过 `AppAlert`、`showToast`、`AppMessageBox` 统一；`AsyncStatus` 接入附件上传、订单/图纸/Word 预览、工艺读取和排期导入。成功、失败、读取中用对应图标和颜色区分，不伪造上传进度。
7. 重量单位、分页条数、原稿缩放从原生 select 改用共享下拉，重量的 kg/g 精度和提交值保持不变。
8. `controls.css` 集中管理以上状态和动画，支持 `prefers-reduced-motion`。业务页不重复复制这套皮肤。

接入时的引用数量：AppInput 40 处、AppSelect 38 处、AppDatePicker 7 处、AppPopover 16 处、AppAlert 45 处、AsyncStatus 7 处。数字包含复用组件，不等同于页面数。
