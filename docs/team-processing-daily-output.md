# 班组加工与个人日产规则

2026年10月19日确认。除库房外全部班组登记自己的加工过程，库存及转出区分本班组已加工和未加工，按实际加工人及加工日期统计日产。沿用现有库存、来源批次、员工选择弹窗和导出组件。

## 加工范围

轧制、线切割、雕刻支持一件大料加工成多件小料，分别记录投入、产出、剩余未加工料及废料。退火、研磨、电镀、检验按现有件数登记完成加工，不要求修改库存件数。库房不登记加工。

## 库存与转出

部分加工须分别记账，例如100件完成60件，则库存为已加工60件、未加工40件。各部分继续关联原来源批次；出库直接使用所选部分的加工状态，混合转出分行记录。状态按班组独立计算，上游完成不代表下游完成。加工内部拆分不重复计重，也不计作外部收发；件数按实际产出变化。

## 加工人和日期

每笔加工必须选择本班组启用的员工，保存员工编号及当时姓名，同时记录操作账号。实际加工日期默认当天，可按实际日期补录。不同员工加工同批物料可分笔登记。提交防重、库存版本校验及权限检查继续保留。

## 日产统计

以有效加工登记的实际发生量统计，按日期、班组、加工人查询和导出。普通加工统计完成件数；拆分加工分别统计投入件数、合格产出件数、重量和废料，剩余未加工料不计产量。一件切成100件时，产出为100件，不是增加的99件。出库次数不影响产量。员工同名或改名不得合并身份；历史未明确登记的产量和人员不猜测补齐。

## 实施与验收

1. 扩展现有加工记录、人员身份和实际发生日期，复用加工子批次分离库存。
2. 按班组提供拆分加工或普通加工表单，选料直接带入，必填字段保持红框与聚焦反馈。
3. 在库存、出库、转料记录及追踪中显示所属班组的加工状态。
4. 加工记录统一承载日期、加工人筛选及产量合计，支持逐笔明细和按加工人汇总的字段选择导出，兼容历史记录。
5. 验证部分加工、多人分次、一件变多件、未加工出库、下游重新加工、重复提交、越权、统计与库存不重复，以及桌面尺寸适配。

本次实施不自动部署或改写生产历史数据；完成后报告检查结果。


## 已实现的使用入口

- 除库房外的班组：库存明细的“加工登记”，或“加工记录”中的“加工登记”。已完成的批次只查看记录，不能重复登记日产。
- 轧制、线切割、雕刻：填写本次投入件数，以及加工产出、未加工余料、加工废料明细，必须选择加工人与实际加工日期。
- 退火、研磨、电镀、检验：填写本次完成件数与重量，选择加工人与实际加工日期。部分完成时自动生成已加工和未加工库存，保留来源关系。
- 唯一查询入口：“加工记录”。按实际加工日期、员工、流水号或材质筛选；不选员工即查看全班组，选择某天即查看当天记录。页面合计覆盖全部筛选结果，分页不影响合计。导出可选择“逐笔加工明细”或“按加工人汇总”，再选择字段。没有独立个人日产页面，也不要求重复登记班组日报。
- 补录按实际加工日期统计；登记时间保留审计用途。缺少实际产量、人员或日期的旧记录保留在明细中，并提示未计入产量。
- 出库使用所选库存的加工状态，转料记录增加“转出时加工状态”可选列，详情与追踪提示也显示该状态。下游加工状态单独计算。
