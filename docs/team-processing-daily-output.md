# 班组加工与个人日产规则

2026年10月19日确认。除库房外全部班组登记自己的加工过程，库存及转出区分本班组已加工和未加工，按实际加工人及加工日期统计日产。沿用现有库存、来源批次、员工选择弹窗和导出组件。

## 加工范围

轧制、线切割、雕刻支持一件大料加工成多件小料，分别记录投入、产出、剩余未加工料及废料。退火、研磨、电镀、检验按现有件数登记完成加工，不要求修改库存件数。库房不登记加工。

## 库存与转出

部分加工须分别记账，例如100件完成60件，则库存为已加工60件、未加工40件。各部分继续关联原来源批次；出库直接使用所选部分的加工状态，混合转出分行记录。状态按班组独立计算，上游完成不代表下游完成。加工内部拆分不重复计重，也不计作外部收发；件数按实际产出变化。

## 加工人和日期

每笔加工必须选择本班组启用的员工，保存员工编号及当时姓名，同时记录操作账号。实际加工日期默认当天，可按实际日期补录。不同员工加工同批物料可分笔登记。提交防重、库存版本校验及权限检查继续保留。

## 日产统计

以有效加工登记的实际发生量统计，按日期、班组、加工人查询和导出。普通加工统计完成件数；拆分加工分别统计投入件数、合格产出件数、重量和废料，剩余未加工料不计产量。一件切成100件时，产出为100件，不是增加的99件。出库次数不影响产量。员工同名或改名不得合并身份；历史未明确登记的产量和人员不猜测补齐。

## 班组概览工单统计（2026-11-07）

- 工单按流水号去重，同号分批、重复工序、返工不累加工单数；共投按关联的实际流水号计数。
- 今日在途工单：截至当前，本班组已经接收、还有正常料尚未全部加工完成的流水号。此前收到的未完成物料也计入；上序已发出但本班组未签收的料单独显示为待签收。
- 今日、本周、本月加工工单：按工厂时区的自然日、周一至今、月初至今，统计实际登记过加工的流水号。已完成是其中截至当前没有未完成在库批次的流水号，按最后一次实际加工日期归入周期；后续重新来料或返工未完成时不计为整单完成。这是当前完成情况，不是历史时点快照。
- 当前逾期工单：复用交期页的约定交期和实际转出判断，同一流水号任一已确认批次逾期未交完即计一次；已交完、已取消和尚未确认的计划不计入。
- 库房显示收发工单、待转出和已转完，不统计加工；库房交期沿用现有不考核规则。已转完要求本期有实际转出，且当前本班组无该流水号的剩余正常料。
- 质量问题可切换今日、本周、本月，按期间发现且当前账号可见、涉及本班组的问题统计，处理状态取当前状态。
- 库存明细默认只显示当前有料；件数和重量均为零且没有短缺差异时不显示。已加工但仍在库会继续显示；已转出待下序签收的料不再算本组实物库存。历史记录没有删除，可切换“全部（含零库存）”或查看加工及收发历史。其他筛选条件也可能隐藏记录。

## 已实现的使用入口

- 除库房外的班组：库存明细的“加工登记”，或“加工记录”中的“加工登记”。已完成的批次只查看记录，不能重复登记日产。
- 轧制、线切割、雕刻：填写本次投入件数，以及加工产出、未加工余料、加工废料明细，必须选择加工人与实际加工日期。
- 退火、研磨、电镀、检验：填写本次完成件数与重量，选择加工人与实际加工日期。部分完成时自动生成已加工和未加工库存，保留来源关系。
- 唯一查询入口：“加工记录”。按实际加工日期、员工、流水号或材质筛选；不选员工即查看全班组，选择某天即查看当天记录。页面合计覆盖全部筛选结果，分页不影响合计。导出可选择“逐笔加工明细”或“按加工人汇总”，再选择字段。没有独立个人日产页面，也不要求重复登记班组日报。
- 补录按实际加工日期统计；登记时间保留审计用途。缺少实际产量、人员或日期的旧记录保留在明细中，并提示未计入产量。
- 出库使用所选库存的加工状态，转料记录增加“转出时加工状态”可选列，详情与追踪提示也显示该状态。下游加工状态单独计算。

### 班组加工参数

退火记录可选填炉号、工艺温度要求、实际温度、保温时长；轧制、研磨、线切割、雕刻可选填机台号。参数属于每笔加工登记，正常加工和每次返工分别保存，不继承前一次实际值，不修改工艺原单。温度要求是可记录范围的文字，实际温度独立记录为摄氏度数值；保温时长独立于加工时长，二者同时填写时保温不得超过本次加工时长。

后端 `processing_parameters.py` 定义班组适用字段，并在保存时校验；上下文和列表接口返回适用字段清单。前端 `processingParameters.ts` 与 `ProcessingParameterFields.vue` 统一表单、列表及逐笔导出。退火列表默认显示炉号和实际温度，机加工班组默认显示机台号；其余参数可在记录详情和导出中查看。

原格式产量表对应填写实际温度、炉号、机床编号；轧制表末尾补机台号，退火表末尾补工艺温度要求和保温时长（小时）。旧记录缺失参数保持空白，实际温度为 0 时保留 0。小时制报表最多保留四位小数，数据库仍保存整数分钟。每日汇总不合并不同作业的温度、炉号等参数。迁移 `20261112_0072` 只加可空列，本地应用前备份到 `output/local-services/qa-before-processing-parameters-20261112.sqlite`。
