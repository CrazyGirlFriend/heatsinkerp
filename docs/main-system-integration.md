# 主系统流水号资料接口规范 v1.0

状态：本地已实现查询适配器、受权限保护的查询接口及显式入库接口，尚未部署，未与真实主系统联调。本规范是交给主系统开发方的对接约定，不代表对方现有接口已经支持。当前界面仍使用原演示/手工入库入口；正式切换需要接好主系统并将入库表单接入本页的新接口，不能仅配置地址就认为端到端上线。

## 1. 边界与职责

- 主系统维护流水号及客户/物料资料，我们后端主动按流水号查询。主系统不需要登录本系统，也不需要使用本系统访问口令。
- 流水号是字符串，保留前导零、大小写及内部符号，最长 80 字符；只做精确匹配。不能用转料批次号替代流水号。
- 同一流水号对应一份当前资料，可以有多个历史版本。`revision` 由主系统生成，每次资料或启停状态改变都必须变化，不允许重复用于不同内容。
- 一期不包含主系统库存扣减、入出库回传、工艺排程或批量同步。查询资料不是物料入库，主系统给的成品件数也不是本次实收件数。
- 我们自己的转料批次号、条码、上/下序、实收/转出件数和重量、操作人、时间、接收状态及丢失记录由本系统维护，主系统查询响应不能覆盖这些字段。
- 一期先按现有单据字段完整对接，包括全部九个补充字段。没有值时返回 `null`，不能不传键、用 `0` 代替未知件数，或用“无”代替未知信息。

## 2. 主系统需要提供的接口

**主系统实现；本系统后端调用。**

```http
GET /api/integration/v1/serial-materials?serial_no=001-A%2F%E4%B8%AD%E6%96%87
Authorization: Bearer <专用只读服务令牌>
Accept: application/json
X-Request-ID: <本系统生成的 UUID>
```

- HTTPS，必须使用可验证的证书；主系统为该令牌授予只读流水号资料权限，按最小权限限制可见组织/工厂。主系统负责鉴权、审计和限流。
- 不把令牌交给浏览器、不放进 `VITE_*`、URL或仓库。禁止通过 301/302 跳转到登录页或另一域名；本系统不跟随重定向。
- 200 必须为 `Content-Type: application/json`，UTF-8，响应上限 64 KiB。推荐不缓存敏感资料。
- 不套 `data`/`result` 外壳，返回体就是下面的对象。若主系统已有不同格式，需双方确认后只改适配器，业务流程不直接依赖对方字段名。
- `updated_at` 为带时区的 ISO 8601 字符串，例如 `2026-09-15T08:30:00+08:00`。数据库记录时间和纸质单据显示时间仍由本系统负责。

```json
{
  "schema_version": "1.0",
  "serial_no": "001-A/中文",
  "revision": "17",
  "updated_at": "2026-09-15T08:30:00+08:00",
  "active": true,
  "document": {
    "material_name": "铜钼 CuMo70",
    "material_type": "semi_finished",
    "source_batch_no": "RAW-001",
    "finished_specification": "30×20×2 mm",
    "transfer_specification": "32×22×2 mm",
    "finished_quantity": 500,
    "customer_code": "C-001",
    "technical_requirements": "按图纸交付",
    "product_code": "P-001",
    "part_no": "J-001",
    "material_shape": "片",
    "material_description": "散热物料",
    "outsourced_unit": null,
    "purpose_category": "散热",
    "category_level3": "钼铜片",
    "order_category": "正式订单",
    "special_process": "表面清洁"
  }
}
```

### 字段字典

所有键必传；只有 `document.material_name` 必须为非空字符串，其他 document 值可为 null。顶层身份、版本、时间、启停状态都不可为 null。不接收未知字段，新增字段先升级双方约定。

| document 字段 | 中文含义 | 类型／限制 |
| --- | --- | --- |
| material_name | 材质 | 非空字符串，160 字符 |
| material_type | 物料类型建议值 | 枚举或 null，实收分类由库房确认 |
| source_batch_no | 原单批号 | 字符串，80 字符；不是本系统 CK/TL 条码 |
| finished_specification | 成品规格 | 字符串，240 字符 |
| transfer_specification | 转料规格参考值 | 字符串，240 字符 |
| finished_quantity | 主系统成品件数 | 整数，0～2147483647；不是本次实收量 |
| customer_code | 客户代码 | 字符串，80 字符 |
| technical_requirements | 技术要求 | 字符串，4000 字符 |
| product_code | 编号 | 字符串，80 字符 |
| part_no | 件号 | 字符串，80 字符 |
| material_shape | 形状 | 字符串，80 字符 |
| material_description | 物料说明 | 字符串，2000 字符 |
| outsourced_unit | 外委单位 | 字符串，160 字符 |
| purpose_category | 用途分类 | 字符串，80 字符 |
| category_level3 | 三级类别 | 字符串，80 字符 |
| order_category | 订单分类 | 字符串，80 字符 |
| special_process | 特殊工艺说明 | 字符串，2000 字符；不触发工艺流程 |

物料类型枚举：`finished` 成品、`semi_finished` 半成品、`finished_surplus` 成品余料、`semi_finished_surplus` 半成品余料、`defective` 不良品、`waste` 废料、`sludge` 泥料、`scrap_chips` 屑料。其他分类字段暂为主系统给出的显示文字，不在本系统另造分类标准。

机器可读文件：[响应 JSON Schema](contracts/main-system-serial.schema.json)、[主系统提供方 OpenAPI 3.1](contracts/main-system-provider.openapi.json)。后者的服务器域名为不可用的占位地址，联调前必须替换。`serial_no` 最长 80、`revision` 最长 100、`schema_version` 固定 `1.0`、`active` 必须是真正的布尔值。

### 主系统错误响应

使用真实 HTTP 状态码，不得 200 包装错误：404 未找到、401/403 令牌无效或无权限、429 限流、500/503 服务异常。停用但仍存在的流水号返回 200 + `active:false`，可以查资料但不能新增入库。错误正文可有 `code`、`message`、`request_id`，本系统不向浏览器透传该正文。

## 3. 本系统给前端的接口

这些入口要求本系统登录 Bearer Token，已开启访问锁时还要求解锁 Cookie。使用现有登录与权限规则，不使用主系统服务令牌。

### 3.1 查询资料，不入库

`GET /api/main-system/serial-material?serial_no=<URL编码的流水号>`

登录用户可查；返回上述主系统对象及额外的 `snapshot_hash`（64 位小写 SHA256）。前端只把这个校验值作为不透明标识保存，不自行计算；响应 `Cache-Control: no-store`。接口不创建资料副本表、不生成批次、不增加库存。

### 3.2 库房核实实物后入库

`POST /api/main-system/warehouses/{team_id}/receipts`

仅绑定该库房的班组长可操作；管理员仍仅查看，其他班组不能入库。

```json
{
  "serial_no": "001-A/中文",
  "expected_snapshot_hash": "<查询接口返回的64位校验值>",
  "material_type": "semi_finished",
  "quantity": 100,
  "weight": "10.125",
  "notes": "来料清点完成",
  "idempotency_key": "<本次操作固定的UUID>"
}
```

- 请求只允许上述字段；不能提交或覆盖材质、客户代码等主系统资料。
- 件数为非负整数；重量单位固定 kg、最多三位小数、最多 11 位整数，推荐用十进制字符串传输。件数和重量不能同时为 0；零件数的按重量物料可正常入库。物料类型和说明必填。
- 后端重新查询主系统，核对流水号、启用状态和完整资料校验值。资料变化返回 409，前端展示新资料并要求重新确认，不能静默带入新版。
- 网络读取完成后才进入库存事务，不在持有数据库锁时等待主系统。
- 成功返回 201，响应沿用现有 `MaterialTransferResponse`，生成本系统入库批次和完整客户资料快照，状态为已入库。入库审计同时记录主系统接口版本、资料版本、更新时间和校验值，不存服务令牌。
- 同一操作重试必须复用原幂等键和原请求内容。已成功的请求直接返回原单，不再查询主系统；同键不同内容返回 409。不存在的幂等键不能被当成新资料版本的自动覆盖操作。
- 后续转料沿用现有来源库存关联，复制该批的资料快照，不反复查询主系统；主系统资料后续修改不改历史单据。新入库可以采用新版本，旧库存批次仍保留旧资料。

### 本系统错误码

| HTTP | 含义与处理 |
| --- | --- |
| 401／423 | 本系统登录失效／未解锁 |
| 403 | 非所属库房班组长，禁止入库 |
| 404 | 主系统未找到流水号，不允许编造资料入库 |
| 409 | 资料改变、流水号停用或幂等冲突；按原因重新核对 |
| 422 | 本地请求非法或夹带客户资料字段，修正后提交 |
| 502 | 主系统鉴权/网络/协议异常、错流水号、错误响应结构；联系对接人员 |
| 503 | 未配置主系统或主系统限流；不能显示成“零库存/无资料” |
| 504 | 主系统请求超时，保留前端实收草稿并允许重试 |

## 4. 配置与上线边界

后端环境变量（本机 `.env` 或服务器 `/opt/heatsinkrep/.env`）：

```dotenv
MAIN_SYSTEM_BASE_URL=https://主系统已确认的域名
MAIN_SYSTEM_TOKEN=由主系统签发的专用只读令牌
MAIN_SYSTEM_TIMEOUT_SECONDS=5
```

以上环境变量保留为初始配置；管理员在“系统设置 → 主系统对接”保存后，以数据库中的配置为准，立即生效。页面使用说明与部署前置项见 [主系统对接配置](main-system-configuration.md)。页面配置需要新增迁移 `20260915_0012`，与仅新增查询适配器的早期版本不同。

本系统自动拼接 `/api/integration/v1/serial-materials`。若主系统有网关前缀，可将前缀放在 BASE_URL 中。管理员只能保存服务端白名单内的 HTTPS 地址；普通查询不能指定目标地址。空地址表示未接入，不自动切换成演示数据。连接/读取超时默认 5 秒，可配置 0.1～30 秒；不做自动重试，防止故障时放大请求。单次套接字读取超时不等于端到端总耗时 SLA，需对方限制服务耗时和并发。

目前认证实现为 `Authorization: Bearer <令牌>`，尚未得到主系统方确认。若对方采用 AppKey 签名、OAuth 获取/刷新令牌或其他方式，必须调整适配器后联调；当前不支持自动刷新过期令牌。

部署前需要主系统方提供：测试/正式域名、只读令牌、可用样例流水号、完整 JSON 样例，以及字段/分类含义确认。如需 IP 白名单，放行的是本系统服务器实际出口 IP，不能未经核实就把网页访问 IP 当出口 IP。不得关闭 HTTPS 证书校验来“打通”服务。

本次不自动迁移现有演示资料，也不改当前已部署系统。旧手工入口暂时保留以保证演示可用；**正式切换时必须同时改前端资料选择、关闭手工资料入口，并收紧客户固定字段的改单权限**，不能只隐藏输入框。当前已入库/已确认单据的既有锁定规则仍生效。

## 5. 显示与打印约定

主系统所有客户字段必须在详情及正式纸质转料单上可见；列表可以精简。当前整批打印还是精简明细列，尚未因本接口自动变成全字段打印，需在正式接入页面时配套调整。多条物料 + 全字段不承诺总能挤在一页；应保持整批一个条码、表格化并允许必要续页，不能缩成不可读字号或静默省略字段。

## 6. 联调验收

1. 查询含前导零、中文或 `/` 的流水号，精确匹配，数据不串号。
2. 全部 17 个资料字段完整，空值保留 null，资料版本及时间有时区。
3. 普通查询前后库存和物料记录数量不变。
4. 所属库房确认入库，保存全字段及审计来源；非库房/管理员写入被拒绝。
5. 查询后主系统改资料，提交返回 409 且库存不增加。
6. 同一幂等请求重试只生成一笔库存；主系统随后离线仍能返回已成功单据。
7. 分批转料继承原资料，主系统改资料不影响已入库及历史单据。
8. 未找到、停用、超时、限流、错误令牌、格式不符均明确报错，不能落半条库存。
9. 接好页面和全字段打印后，用真实扫码枪和打印机验收，不以模拟接口测试代替真实主系统联调。
