# 班组材质与类型库存

班组工作台将原“材质归类”拆成两个并列页面：

- **材质库存**：`/team-workspaces/:teamId?tab=materials`，按铜钼、钨铜等材质汇总。旧链接继续打开此页。
- **类型库存**：`/team-workspaces/:teamId?tab=material-types`，按原材料、半成品、成品、余料及各类废料汇总。

两页分别显示一张表，保留独立分页、底部分页位置和原有工作台操作。页码与每页条数写入地址；页面切换不沿用另一页的页码。两页共用既有 overview 接口和库存变更推送，没有增加库存账或修改库存算法。

每行名称和“查看详情”均可点击，进入本班组按该类别精确筛选的库存明细；再点击“明细”查看来源批次，点击批次查看原单。详情保留已出完的来源分类，以便与汇总中的累计收发核对；可用原库存范围筛选缩小到有库存的记录。“返回材质库存”或“返回类型库存”恢复原汇总页码和每页条数，明细分页不会丢失类别筛选或返回位置。未填写材质、未分类性质使用已有接口的专用筛选值，不退化为查全部库存。

表头将“正常可用库存”改为“正常料在库”，“当前库存”改为“在库合计”，“废料库存”改为“废料在库”。这里只明确名称：在库合计仍包含正常料和废料，转出待确认仍单列；这次不推广归属余量的展示方案。

验证：相关前端回归 75 项、TypeScript、修改文件 ESLint 和生产构建通过。独立 Chrome 验证 1366、1440、1920 和 390 宽度；1366 / 1920 下材质表全部列同屏，窄屏仅表格与导航横向滚动，整页无横向溢出。已验证“性质汇总 → 分类明细 → 来源批次 → 原单 → 返回汇总”。浏览器使用隔离的本地接口样例，未读取或写入线上物料，也未使用 Codex 内置浏览器。
