# 转料单字段补齐：后端交付与测试记录

日期：2026-09-06。

## 交付范围

- 转料单新增 17 个可空字段，保留旧客户端和历史记录兼容性。
- 成品件数与本次转料件数、原单批号与自动转料批次号分别存储。
- 七种物料类型；数量和重量均非负，至少一个大于 0。
- 创建、修改、接收、作废产生真实操作历史，与业务更新同一事务提交。
- PATCH / 确认支持 expected_version，拒绝过期单据版本；接收后全部字段锁定。
- 列表支持按原单批号、编号、客户代码和材质搜索；详情包含历史，列表不重复加载历史。
- Alembic 新版本 20260906_0005 保留旧数据，不伪造历史字段或旧操作记录。

## 已执行验证

测试使用独立 Python 3.12 虚拟环境和临时 SQLite 数据库，没有连接线上数据库。

1. 后端全量回归：135 passed，303.27 秒。该轮开始采集用例后新增了审计失败回滚用例。
2. 最终转料专项重跑：15 passed，54.66 秒，包含新增回滚用例。与全量回归存在重叠，不相加作为总用例数。

专项覆盖：完整字段创建/编辑/清空/返回、七种类型、成品数量独立、仅重量交接、数值和文本边界校验、字段伪造拒绝、幂等重试与载荷冲突、版本冲突、确认后全字段锁定、无变化编辑不产生伪历史、作废历史、审计写入失败时业务更新和确认回滚、旧字段兼容、搜索以及存量 SQLite 迁移和数据库约束。

两轮测试均只有第三方 Starlette/AnyIO 的弃用警告，无业务失败。回滚测试初次运行时错误地用管理员视角与班组长视角比较 allowed_actions；已修正测试使用相同账号后通过，未放宽业务校验。
