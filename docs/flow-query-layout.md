# 流转查询与空页布局修正

日期：2026-09-27。范围：前端导航、扫码入口及普通页面高度；不改变库存、权限、业务接口或数据库。

## 入口

- 转料记录：按批次筛选、扫码、详情和打印。
- 全链路追踪：管理员按完整流水号查看跨班组历史，不与单批次查询合并。
- 独立扫码页及其最近扫描列表移除，扫码复用转料记录原有弹层。点击“扫码查询”或在非编辑状态按 F2 打开；键盘模式扫码枪保持可用。
- 旧 `/scan`、`/transfer-batches/scan` 地址继续工作，保留批次号、列表筛选和锚点。带批次号时打开原详情，无批次号时显示扫码框。历史 CK 查询兼容保留。
- 班组工作台的扫码、收发历史和原有三级导航不变。管理员仍不能代班组收发，班组账号不会获得全链路权限。

## 布局

之前班组表格已修正，但普通管理列表仍被共用样式限制为按内容收缩，导致空页或少量记录时只剩上半块面板。

本轮补齐转料记录、班组管理、班组长管理、全厂库存明细，以及班组收发历史的空状态。面板填满可用高度，分页位于底部；数据行保持原高度，超过一屏仍整页纵向滚动。没有补空白数据行，也没有修改默认 10 条和 10/20/50/100 的选项。

- 13 个测试文件共 143 项相关测试通过：首轮 142 项；迁移扫码账号切换保护测试后，转料列表 19 项重跑通过；最后导航外壳 9 项重跑通过。

- 只使用一套独立 Chrome、本地隔离 SQLite 后端及本地 Vite。未打开 Codex 内置浏览器，未调用或修改生产库存。
