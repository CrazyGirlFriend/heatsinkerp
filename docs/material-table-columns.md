# 物料列表独立字段展示

更新日期：2026-09-27

## 展示规则

- 一列只展示一个业务字段，不再把件数与重量、物料类型与业务上下堆叠或用斜线合并。
- 库存明细默认列：流水号、材质、物料类型、本班组业务、来源（车间显示上序班组）、当前件数、当前重量 (kg)、操作。
- 物料类型表示物料性质，如半成品、成品、废屑；业务表示本次安排的工作，如检验、去毛刺。两者继续使用原有数据，分别显示。
- 库存明细、待接收、入库记录、出库记录、丢失记录、材质/性质结存、转料记录，以及相关明细和出库选料表的件数与重量分别成列。
- 转料记录的批次号和流水号独立成列；流水号收发详情的材质、规格、来源、去向、登记人、登记时间分别成列。
- 日期与时间属于同一个时间字段，保留完整时间；转料记录保留原记录的计量单位。
- 维持居中、单行、原字号和分页。列宽不足时在表格内部横向滚动，不使整个页面横向溢出。材质/性质结存固定首列，滚动后仍可对应物料。

## 已保存的显示列

原有 `stock_balance`、`owned_balance`、`dispatchable_balance`、`pending_transfer` 配置分别展开为对应件数、重量两列，保留顺序与显隐选择并去重。用户点击应用前不覆盖原存储。

件数和重量可独立选择显示。已有自定义配置不会自动显示其他新增默认列；如需本班组业务，可在“显示列”勾选，或恢复默认。
