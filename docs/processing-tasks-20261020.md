# 班组加工任务与调研整理

## 功能范围

- 除库房外，班组长可在“班组设置 → 加工任务”维护本班组的具体任务；管理员可维护各班组任务。任务支持启用、停用和改名。
- 加工登记记录对应业务、具体任务、加工人、实际加工日期及本次完成量。业务从当前物料带入，可在正常加工时调整；任务目录已配置时必须选择任务。
- 同一批实物可依次完成不同任务。例如 100 件先粗磨，再由另一人精磨，形成两条各 100 件次的工作记录，实物库存仍是 100 件。
- 任务目录是可选任务清单，不表示每批料必须做完全部任务。同一实物路径不允许重复登记同一任务的首次加工，需要重复处理时使用返工。
- 部分加工保留剩余料的原有任务状态，不把新任务记到尚未加工的剩余料上。正常跨班组接收后开始接收班组的任务记录。
- 返工沿用被选原记录的业务和任务，包括改名、停用后的历史名称；历史未登记的业务或任务不猜测补填。
- 加工记录支持按业务、任务、人员、日期等筛选，明细导出包含业务和任务；汇总导出按加工人、日期、业务和任务分组，首次加工与返工分别统计。工作量使用“件次”，不当作新增实物库存。
- 本次不新增独立日产页面。既有加工记录及其筛选、汇总导出承担查询和报表入口。

## 调研文档范围

Word 按库房、轧制、退火、研磨、线切割、雕刻、电镀、检验分别整理，共八页，文字全部为黑色。只保留需要班组明确的问题：流程差异、重量计算与称重偏差、废料分类和处理、共投料实际分摊、现行日产报表，以及电镀增重计算标准。上述尚未确定的生产标准未写成自动计算规则。
