# 业务页阅读样式统一（2026-09-13）

以已确认的流水号台账为基准，不重新设计一套主题。

## 已应用范围

- 八个班组共用的待接收、库存明细、出库记录、丢失记录、材质归类、数据分析，以及库房入库记录。
- 全局转料记录、扫码查询、流水号追踪、班组管理、班组长管理。
- 全厂总览及两套大屏的布局、登录和访问验证页不变；弹窗仍保留独立滚动。

## 统一规则

- 正文 16px、普通字重；辅助文字 14px；表头 15px、中等字重、浅灰底。白色内容区，紫色用于操作与选中状态。
- 控件 40px 高、15px 文字；单行表格约 63px 高。双行标识、条码等保留必要高度，不强压成单行。
- 所有分页业务列表默认 10 条，可选 20/50/100 条；页面随行数增长，纵向滚动发生在整页，窄屏表格仍可左右滑动。
- 转料单号与流水号合并为一个主次信息列，保留材质、流转班组、数量重量、状态、时间，共六列。扫码和详情入口不变。
- 管理页去掉重复统计栏和重复结果计数；班组长页保留简短的管理员维护范围说明。
- 数据分析图表保留六张，放大标题与图例并增加图内空间；不改变统计口径或图表筛选联动。
- 加急动效、日期筛选、批量出库、条形码、打印、库存与确认权限均保留。
