# 物料详情居中弹窗

## 调整范围

- 库存分类明细、流水号详情、转出待签收批次、转料单详情和历史合并记录统一居中显示。
- 班组工作台及流转查询的转料详情不再使用右侧抽屉或宽屏分栏，打开详情不改变列表宽度。
- 弹窗自适应屏幕宽度，高度不超过视口减去 48px；长内容在正文内滚动，标题及已有底部操作区保持可见。
- 保留原单资料、条形码、分页、权限、实时刷新及打印行为；待接收详情仍不提供打印。
- 确认、作废或交期提交期间继续阻止关闭。关闭嵌套批次详情返回上一层，普通关闭恢复触发按钮焦点。
- 未修改业务接口、生产数据、侧边栏、创建/编辑表单和图形预览页。
