# 紧凑工作台与测试数据改版（2026-09-11）

## 实施范围

按照本次截图反馈，菜单统一为两级：物料流转、班组、系统设置为一级；库房、轧制、退火、研磨、线切割、雕刻、电镀、检验均为“班组”的二级入口。收起时仍由一级图标展开二级菜单，不改变归属；系统设置仅管理员可见。

保留 Vue 3、Element Plus 和现有紫色主题，缩小标题区、统计区与留白。班组台账使用 Element Plus 表格；出库记录一张 CK 批次单占一行，显示条形码，点击“查看整批”集中查看所有明细。原单规格、追溯等详细内容保留在详情中。

转料记录、班组台账、班组管理、班组长管理默认每页 20 条，可选 50、100 条。20 条指每页实际加载的记录数，不是把 20 行硬挤进所有屏幕高度；表格内部可滚动，分页栏固定在表格下方。数据不足一页时显示实际数量，材质纵览按真实材质汇总，不人为补行。

保留账号及密码、班组、登录会话、数据库结构、迁移版本和条码计数器。删除在一个数据库事务中完成，自关联来源记录先删除子记录，始终保留外键检查。清理工具不自动在启动、升级时运行，不删数据库，不重置编号。

执行顺序为停止业务写入、生成新的完整数据库备份、确认目标及预览数量、执行清理、生成测试数据、恢复服务。需要恢复时使用本次清理前的备份，不把测试库备份当作线上备份。

```bash
python -m app.reset_business_data
python -m app.reset_business_data --apply --confirm-database <准确数据库名或路径> --backup-file <本次完整备份文件>
```
