# 班组工作台视觉舒适度复查

日期：2026-09-13。范围：本地库房工作台，流水号台账与待接收页面。使用用户允许的独立 Chrome，不使用内置浏览器。本轮只审查，不修改应用代码、数据或线上版本。

目标：查找流水号、辨认库存及待接收状态时，减少视线来回寻找与无效视觉强调。

## 1. 流水号台账 — 可读，但重点过多

![流水号台账](../output/playwright/comfort-audit-20260913/01-serial-ledger.png)

本轮截图：1440 × 900，库房班组账号，默认 20 条/页，数据已加载。已打开原始截图检查。

优点：表头与正文有区分；数量右对齐；日期和单位弱化；入库、出库入口可见；没有重新引入大标题和统计卡片。

问题：

- 顶部同时承载八个页签、搜索、日期、加急、三项查询操作和四项业务操作。控件虽放在同一行，却未明确分成“查找”和“办理”两组。不是缺少空白，而是缺少分组。
- 实心紫色页签与实心紫色“新建出库”都是强强调；每行流水号又有紫色粗体及另一侧紫色“详情”。同一行提供两个详情入口，左右两边同时抢注意力。
- 行内流水号、可用件数和重量同时加粗，重复十多行后形成三条明显的视觉竖带。普通数据几乎全是重点，加急的业务优先级反而不够突出。
- 主体字体集中在较小字号；导航、页签和表格的层级更多靠颜色，而非稳定的字号/字重关系。侧栏较松、工具栏较满，两处节奏不同。
- 行高与列间距是统一数值，但流水号、材质规格、库存数量之间没有语义分组。查一条料时需要横跨整行对照。

可访问性观察：当前页签与加急均有文字辅助，不只依赖颜色；日期和次要文字较小，右侧详情命中区域窄，需要进一步检查缩放与键盘操作。此截图不构成完整可访问性验证。

建议顺序：先分离顶部“导航 / 查询 / 办理”层级；再降低普通流水号和重复详情入口的视觉权重；最后按内容调整列宽和行内留白。不先更换字体、不增加装饰或卡片。

## 2. 待接收 — 表格可读，任务重点错位

![待接收](../output/playwright/comfort-audit-20260913/02-pending.png)

本轮截图：同一浏览器、1440 × 900，点击待接收页签后等待记录加载结束。已打开原始截图检查。

优点：搜索与扫码在同一行；批次/流水号、材质/类型、人员/时间采用成对排列；数量和重量带单位；加急有明确文字标签。

问题：

- 页面任务是接收物料，但最强的实心按钮是“新建出库”；“查看来料”和“查看整批”视觉上反而更弱。当前任务与视觉主操作不一致。
- 前三行属于同一个 CK 批次，却重复三遍长且加粗的紫色批次号。同批关系不明显，用户先看到的是三段醒目的编码，而非一批料包含三项明细。
- 长批次号占据第一列主要视觉重量，真正区别这三行的流水号却用更小、更浅的次要文字显示。身份、关联、状态的优先级没有按使用任务重新组织。
- 搜索、扫码、日期、加急以及入出库混在一个连续控件带里。当前两行总体高度不大，不需要再压缩；需要在保持两行的前提下重新分组。
- 双行内容行高约 60px，本身并非错误；问题在于左侧长编码很满，右侧短字段之间又有大块横向空白。统一加宽或缩窄所有间距都不能解决这种不均衡。

可访问性风险：小号浅色流水号承载重要身份信息；扫码输入与搜索输入需要明确不同用途，不能只依赖相近的占位文字。截图无法确认屏幕阅读器朗读、键盘路径或扫码设备行为，本轮不作相关通过声明。

## 建议的统一方向

1. 保留两行顶部结构：第一行左侧页签、右侧业务操作；第二行组织搜索、扫码、日期与查询。不是额外增加一排，更不是恢复大标题/统计卡片。窄宽度下按实际可用宽度折行，不牺牲输入可读性。
2. 区别“所在页面”和“要办的事”：页签保留明显选中状态，但不与当前页面主要业务按钮同时使用同等强度的大色块。待接收优先突出查看/接收来料，出库入口保留但弱化。
3. 普通数据回到常规字重，强调限定在当前任务的关键值、加急或异常；流水号、批次号保持可点击和完整查询能力。若收起重复详情入口，必须保留清晰且键盘可用的详情入口。
4. 列宽服从内容：身份列给足稳定宽度，数量列紧凑对齐；相关字段靠近、不相关字段拉开。对同批多明细探索分组展示，但不改变批次与流水号业务语义、不隐藏核对信息。
5. 字体先修层级和可读性，不先换字体库。中文正文与关键身份信息保持足够大小，辅助日期可以弱化，但不应让流水号成为最难读的一行。

## 范围与证据限制

这是两个桌面页面的视觉与任务层级审查，不是全系统审查、功能回归或完整无障碍测评。截图为本轮独立 Chrome 新采集，非旧截图和概念图。未操作入库、出库、接收或加急，未修改数据。未修改应用代码、未部署。建议仍需一张完整效果稿验证组合后的视觉质量，不能仅凭 CSS 数值认定“高级”或“舒服”。
