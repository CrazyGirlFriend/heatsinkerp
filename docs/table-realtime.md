## 交互与资源

- 更新不销毁表格或时间线，不回到第一页，不清空搜索草稿，不覆盖单据编辑草稿。管理员列表只在原页码已超出最新页数时收至最后有效页。
- 后台读取失败保留上次数据，并显示同步失败与重试入口；连接断开显示重连提示，不把旧数据伪装为已同步。
- 连续通知在 100ms 内合并。一次读取未完成时不并发启动相同视图的下一次后台读取，有新通知则完成后补读一次。
- 同一页面和嵌套详情共享一条轻量通知连接；各自按筛选读取数据。没有业务事件时不定时刷新表格。
- 页面隐藏、离开、关闭详情时取消该视图的订阅及排队任务。最后一个使用者退出后关闭共享连接；重新可见后重新获取最新状态。
- 管理接口和物料接口重读时不复用旧缓存。没有数据写入、测试数据重置或迁移。
