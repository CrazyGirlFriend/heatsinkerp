# 班组工作台字体与间距样板（2026-09-13，本地）

范围：沿用既有紫色主题、已对齐侧栏及两级导航，只精修班组工作台；不重做全厂总览、机器人或业务流程。使用独立 Chrome，未使用内置浏览器。

## 1. 流水号台账：调整前

![调整前的台账](../output/playwright/workspace-type-20260913/01-before-ledger.png)

- 优点：操作、日期、加急筛选及 20/50/100 分页已经齐全，表头和正文可区分。
- 问题：1366×768 下工具栏高 104px，录入按钮被挤到第二行，左侧空出半行。表体行高只有约 30px，留白集中在操作区，读数区反而拥挤。
- 问题：流水号和详情同样使用亮紫色，数量、材质、时间的视觉权重接近；输入框 36px 高，旁边按钮 32px 高，控件基线缺乏一致性。
- 风险：材质、规格、时间在窄屏频繁省略；仅凭截图不能确认键盘焦点、所有弹窗和屏幕阅读器体验。
- 调整方向：保持单个紧凑工具栏，统一 36px 控件；增加表格行内呼吸空间，以字重、数字对齐及辅助文字颜色建立层级，不扩大页面标题区。

## 2. 待接收：调整前

![调整前的待接收](../output/playwright/workspace-type-20260913/02-before-pending.png)

- 优点：搜索与扫码已经同排，来源、数量和查看整批入口完整。
- 问题：批次号仅 12px，和下方辅助流水号接近；数字在宽表格中偏弱，单位与数值间的关系不够清晰。单行台账与双行记录的字体、页脚和按钮高度不统一。
- 调整方向：保留现有字段与两行信息结构，主记录 14px、主数字 15px，辅助信息 12px；双行记录使用统一行内间距，日期和加急筛选保留。
- 检查边界：本次只读浏览，不提交或确认任何转料；不据此声称全部业务或完整无障碍合规。

## 可复用的样式约定

规则集中在 `frontend/src/styles/team-workspace.css`，所有选择器限定在 `.team-workspace` 内；不覆盖侧栏、全厂总览、独立大屏或全站弹窗。

| 角色 | 规格 |
| --- | --- |
| 正文、主记录编号 | 14px；记录编号 600 字重、深紫色 |
| 核心库存数值 | 15px / 600；等宽数字，台账右对齐 |
| 时间、单位等辅助信息 | 12px；灰蓝色，保留可读对比度 |
| 表头与控制文字 | 13px；表头 600、操作按钮 500 |
| 输入框、工具栏按钮 | 36px 高 |
| 单行表格、表头 | 40px / 44px；双行记录按内容自然增高 |
| 表格与工具栏左右内边距 | 16px，窄屏 12px |
| 控件间距、页签到内容间距 | 8px / 12px |

维持既有紫色主题、明显的表头底色、选中页签与 20/50/100 分页。不新增装饰卡、统计头部或远程字体依赖。
