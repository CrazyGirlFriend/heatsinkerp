# 检验、巡检与质量反馈

2026-10-19 按最新讨论确认。

## 检查事实

- 检验班组库存可直接登记检验；巡检仍用于检验人员到生产班组检查已加工物料。
- 检验范围单选抽检或全检。检查手段多选目视、显微镜；检查项目多选外观、尺寸、重量。
- 检验人员从检验班组的启用员工名单选择。检查时间、实际检查件数、不合格件数必须明确；合格件数由检查件数减不合格件数得到。
- 全检件数必须等于所选批次的当前在库件数。抽检结论仅代表样本，不能推定未检部分合格。
- 尺寸、重量要求及实测结果可记录；说明选填，不预设公差或自动判定。
- 保存检查不增减库存，不拆分实物批次，不计入加工产量，不自动发货、转投、返工、锁定或放行。

## 质量反馈

- 各班组工作台设质量反馈页签，巡检和检验发现的不合格问题统一进入。
- 检验员多选问题涉及班组；发现地点与问题涉及班组分开记录，不以发现地点自动认定责任。
- 一条不合格检查对应一条问题，多个班组分别回复，不重复统计不合格件数。复检关联原问题，不生成重复问题。
- 普通班组仅能查看涉及本班组的问题，并提交本班组反馈。检验班组和管理员可查看全部；仅检验班组长账号能明确处理意见、调整涉及班组、结束或重新打开问题。
- 处理方式包含待判定、返工、发货、转料、班组内转投、报废和其他处理。只是处理意见，实际操作继续从现有业务入口人工办理。
- 待处理、处理中、已结束表示问题跟进状态。回复不自动关闭问题；复检合格不自动关闭问题；结束问题不把检查结果改成合格。
- 人员、时间及每次反馈和处理决定保留历史。写入使用版本与重复提交保护。

## 历史与核对

- 历史加工完成不推定为检验合格。旧检查缺少方式、项目时显示历史未记录，不猜测补写。
- 历史巡检锁定不在迁移时偷偷解除；检验班组长可在对应质量反馈中明确手动解除，操作留痕。新检查不再自动产生锁定，复检也不自动解除旧锁定。
- 检查与质量处理事件进入批次追踪；库存详情可查看检查记录、从问题定位原批次追踪。
- 列表支持搜索、筛选、分页、全屏和按当前筛选结果选择字段导出。
