## 必查视觉表面

- 字体：沿用中文系统字体栈，28px 页面标题，15px 主要数据，13–14px 辅助字段和状态；编号和数量使用等宽数字特性。长备注可换行。
- 布局：白色顶栏和工作区、默认 96px 浅色导航。桌面详情为实际网格列，打开后缩小列表、关闭后恢复；右侧操作区固定，正文独立滚动。导航展开仍推动主内容。
- 颜色：蓝色主操作 #2f5de5、深色正文、浅灰分隔；用户拒绝的大面积蓝色标题带未引入。待接收/已接收/已作废以橙、绿、灰的图标和文字共同表达。
- 图像与图标：品牌、导航、班组、状态和移动信号均沿用 Element Plus 图标库。没有照片或插画资产需求；品牌采用项目已有 Box 图标。条码由 JsBarcode 生成真实 Code 128，不使用概念图中的条码像素。
- 内容：保留一期转料、扫码、追踪和管理边界。筛选班组入口展开后仍能独立指定转出方和接收方。未加入新生产指标、库存、工单或额外模块。

## 动画和业务交互验证

- 待接收且未锁定才挂载移动信号。实际浏览器中 430ms 前后的 transform 不同，动画正在运行；已接收、作废记录没有循环信号。
- 模拟确认接口 503 后，详情仍为 pending，流动保持，允许重试。
- 故意延迟成功响应：等待期间保持 pending 和流动；响应到达后，列表与详情都变为 received，移动信号一起移除，确认按钮消失。
- 等待确认时尝试点击另一批次，选中项仍保持原单，避免 A 单确认结果落到 B 单。
- 确认请求携带幂等键。减少动态效果偏好下移动信号 display=none、animation-name=none；静态箭头和状态文字继续显示。
- 编辑弹窗可打开并取消；筛选接收班组后返回的 14 条记录全部指向研磨班组；扫码输入批次并回车打开对应详情。
- 打印调用时校验存在两联文字、两个真实条码 SVG 和打印样式标记；未调用实体打印机。
- 证据：`motion-before-results.json`、`confirmed-results.json`、`extras-results.json`、`received-stopped.png`。
