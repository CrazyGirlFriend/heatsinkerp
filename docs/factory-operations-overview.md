# 全厂运行概览

入口：`/factory-analysis`。运行概览、生产完成、检验与质量、库存与交接在同一长页面依次展示。顶部固定分区导航，点击后滚动定位，手动滚动时同步高亮所在分区；原 `view` 链接仍可定位对应内容。分区跳转保留筛选和已加载数据。

## 展示与数据

| 内容                   | 数据来源及含义                                                                                                                                                 |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 全厂在库、班组库存分布 | `/api/factory-overview`；未转出库存，在途单列，避免重复计数                                                                                                    |
| 待交接                 | 当前内部待签收与对外待确认批次，不受统计周期限制                                                                                                               |
| 逾期未交完、今日待交   | `/api/production-schedules/overview`；复用排期节点状态判断，不截取第一页计算总数                                                                               |
| 按期交接率、履约圆环   | 周期内按时完成节点 ÷（按时完成＋逾期完成＋逾期未交完）；按实际转出履约，签收单独记录。库房、取消节点和未确认且无批次的计划不参加考核，无可考核节点返回 `null`  |
| 收发趋势               | 入库与对外出库（含检验发货），内部转料不计新增产出                                                                                                             |
| 班组加工完成量         | `/api/factory-performance?include_activity=true`；使用 `activity.teams` 分班组展示正常加工、返工，支持选择班组；不显示跨班组加工合计                           |
| 库存滞留               | 从本班组接收物料的时刻起算，加工、拆批和同班组转投保留原接收时间；转入下一班组后从该班组接收时刻起算。点击进入对应滞留范围，明细汇总行取剩余批次中最长滞留时长 |
| 质量跟进               | 所选周期发现且当前账号可见的问题状态与问题类型；不混算抽检、全检和复检合格率                                                                                   |

周期支持 7 / 30 / 90 天及已有链接指定的 1–365 天；库存和未履约待办始终表示当前状态，趋势及周期履约随周期变化。未选择的周期天数不会改变当前库存。

## 交互与组件

- `DashboardCard`、`DashboardMetric` 为共享卡片组件，图表复用 `LedgerChart`，控件复用现有 Watermelon 主题组件。
- 点击库存柱条进入对应班组库存或待签收；逾期指标进入已筛选排期；待办进入具体交期明细；质量入口进入检验班组质量反馈。
- 页面可见时每分钟刷新；更新失败保留同周期旧数据并提示，首次失败显示缺失状态。切换周期清除旧范围数据，忽略过期请求结果。
- 跟随系统明暗主题；指标、页签及图表有过渡动画，尊重减少动态效果设置。

## 班组概览

八个物料班组的三级菜单新增“概览”，入口 `/team-workspaces/:teamId?tab=dashboard`，统一复用 `TeamDashboard`、`DashboardDonut` 和已有指标卡片。

- 在库流水号按当前实物剩余库存去重；同号多批只算一次，共投按关联流水号去重，未填流水号的批次单独提示。
- 未加工、部分加工、本批已加工完成、历史进度未标明分别统计剩余数量/重量，已转出待签收的料不计入本班组在库。废料类不参加加工进度统计。库房展示在库数量、重量，不虚设加工进度。
- 加工状态、物料类型和质量问题用环形图，可切换件数/重量。质量默认近 30 天，支持 7/30/90 天，统计当前账号可见且涉及本班组的问题，复检不重复计数。质量状态是问题处理状态，不是产品合格率。
- 点击数字或图例进入已筛选的库存、待签收、质量反馈；质量明细与导出保留概览的班组、发现日期及处理状态。
- 在原库存概览接口上仅为此页面传 `include_summary=true`，避免所有库存页都执行新汇总；由服务端全量统计，不用列表第一页凑总数。沿用实时刷新、明暗主题和减少动画设置。

## 四个分析页（2026-11）

四页共用 `DashboardToolbar`、`DashboardMetric`、`DashboardCard`，筛选及明细使用现有主题控件和 `AppDetailTable`。

四个分析区共用页面滚动，不再通过页签隐藏内容。运行概览与库存区共享统计天数（默认近 7 天）和数量/重量单位，生产、质量区保留各自日期和业务筛选；分区定位不改变统计周期。当前库存与待交接保持当前时点含义。

- **运行概览**：当前库存、待交接、逾期节点、周期履约；库存分布、交期待办、收发趋势/班组加工对比、滞留和质量跟进均可继续查业务。
- **生产完成**：默认“班组对比”，每个班组独立显示正常加工和返工量，不展示跨班组总量。点击柱条或选择班组后，通过 `team_id` 获取该班组的完成量、登记笔数和周期趋势，可返回全部班组对比；“流水号任务”保留具体任务查看。日期、班组、流水号筛选同时作用于汇总、趋势和导出。件次表示工序加工量，不是成品数量；共投产出分到多个流水号时，加工登记按记录 ID 去重。
- **检验与质量**：分别选择巡检/检验、抽检/全检、首次/复检，展示材质合格率、受检与不合格件次、质量问题状态、趋势和材质明细。没有检查记录时合格率显示“未检查”，不显示为 0% 或 100%。
- **库存与交接**：库存分布、库存滞留、待交接时长、物料类型、流水号及材质排行直接排列展示，取消内部再次切页；保留当前库存与周期收发的区别及今日转料入口。

四页均支持明暗主题、刷新和加载/错误状态；原先仅统计最近一个加工任务的 `production` 数据仍供任务视图使用，全班组视图使用独立 `activity` 字段。`activity` 新增重量、登记笔数、班组明细，并支持流水号过滤。

## 图表与卡片（Watermelon 参考）

- 运行概览以收发趋势/班组加工对比与交期待办为主图，班组库存、库存滞留、质量跟进为辅助卡片。
- 生产与库存收发指标使用真实日期序列绘制微型趋势图；当前库存、当前逾期没有历史序列，不补造趋势。
- 生产完成默认使用 `TeamProductionChart` 班组对比柱图（与运行概览复用），选择班组后展示该班组每日/每周/每月分组柱图，正常加工与返工分开比较；质量以材质合格率趋势为主图，材质比较与问题排行为辅助图。没有对应数据的图表不占独立卡片，全部为空时只展示一个空态。生产和检验明细通过 `AppDisclosure` 展开。
- `DashboardDistribution` 复用于库存滞留和物料类型：横向占比条、类型颜色、数值与占比同时显示。负数库存差异保留数值提示，不绘成负占比；存在负数时不显示比例，避免与净合计混淆。
- `useDashboardChart` 统一柱条、淡面积折线、坐标轴和主题提示框；图表入场 800ms、数据更新 400ms，遵循页面动画开关和系统减少动态效果设置。
- 视觉构成参考 [Capitalio](https://ui.watermelon.sh/dashboard/capitalio-dashboard)、[Medesk](https://ui.watermelon.sh/dashboard/medesk-dashboard)、[Library](https://ui.watermelon.sh/dashboard/library-dashboard) 官方源码，适配为本项目 Vue 组件；来源与许可见 `frontend/src/components/watermelon/NOTICE.md`。
