# 全厂运行概览

入口：`/factory-analysis`。默认进入运行概览，原生产完成、检验与质量、库存与交接分析仍可通过页签进入。

## 展示与数据

| 内容 | 数据来源及含义 |
| --- | --- |
| 全厂在库、班组库存分布 | `/api/factory-overview`；未转出库存，在途单列，避免重复计数 |
| 待交接 | 当前内部待签收与对外待确认批次，不受统计周期限制 |
| 逾期未交完、今日待交 | `/api/production-schedules/overview`；复用排期节点状态判断，不截取第一页计算总数 |
| 按期交接率、履约圆环 | 周期内按时完成节点 ÷（按时完成＋逾期完成＋逾期未交完）；按实际转出履约，签收单独记录。库房、取消节点和未确认且无批次的计划不参加考核，无可考核节点返回 `null` |
| 收发趋势 | 入库与对外出库（含检验发货），内部转料不计新增产出 |
| 加工登记趋势 | `/api/factory-performance?include_activity=true`；跨班组及加工任务累计正常加工、返工件次。与原接口聚焦单个任务的 `production` 字段分开，不能解释为成品产量 |
| 库存滞留 | 未加工料从本班组接收起算，加工后从加工完成登记起算；未加工余料拆批和同班组转投保留原起算时间。点击进入对应滞留范围，明细汇总行取剩余批次中最长滞留时长 |
| 质量跟进 | 所选周期发现且当前账号可见的问题状态与问题类型；不混算抽检、全检和复检合格率 |

周期支持 7 / 30 / 90 天及已有链接指定的 1–365 天；库存和未履约待办始终表示当前状态，趋势及周期履约随周期变化。未选择的周期天数不会改变当前库存。

## 交互与组件

- `DashboardCard`、`DashboardMetric` 为共享卡片组件，图表复用 `LedgerChart`，控件复用现有 Watermelon 主题组件。
- 点击库存柱条进入对应班组库存或待签收；逾期指标进入已筛选排期；待办进入具体交期明细；质量入口进入检验班组质量反馈。
- 页面可见时每分钟刷新；更新失败保留同周期旧数据并提示，首次失败显示缺失状态。切换周期清除旧范围数据，忽略过期请求结果。
- 跟随系统明暗主题；指标、页签及图表有过渡动画，尊重减少动态效果设置。
