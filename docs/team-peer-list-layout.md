# 班组同级列表单行排版

2026-09-27：本地开发与验收完成，待发布。

## 范围

待接收、出库记录、库房入库记录、丢失记录、材质结存和物料性质结存。收发历史沿用已有图形，不改为表格；库存明细、侧边栏、接口及库存计算不变。

- 批次号与流水号、材质与类型、经办人与时间分列。类型与业务在同一行展示，长文字省略并可悬停查看；流水号保持前导零，加急标记同行显示。
- 件数与重量横向排列，零值保留，不通过缩小数字或删除单位压缩行高。单行样式仅应用于上述列表，详情、出库选料及纸质转料单不受影响。
- 出库记录中的条码改为批次号悬停或键盘聚焦时预览；点击批次号仍打开原单。独立批次、合并打印、待接收不允许打印及权限规则保持原样。
- 入库说明移至原有入库单详情与打印单；丢失原因仍在列表中单行显示，长内容悬停查看。
- 默认每页 10 条，可切换 20/50/100；保留整页滚动、固定操作列及空态完整面板。列宽不足时表内横向滚动，不再强制把字段挤成上下两行。

## 验收

- 页面、材质结存、收发历史、原单详情及合并打印共 75 项组件回归通过；新增覆盖四种记录页拆列、前导零、数值与明细入口、出库勾选合并打印。
- 修改文件 ESLint、TypeScript 检查与生产构建通过。构建仍有既有图表分包大于 500 kB 的提醒。
- 使用一个独立 Chrome 会话检查六个页面在 1920×1080、1440×900、390×844 的布局，并补查 2560×1440 出库记录。数据行高为 44–49px；件数、重量同行；无页面横向溢出。较窄屏幕通过表内滚动查看其余列。
- 鼠标及键盘条码预览、原单打开、长流水号、加急标记、三位小数和含换行的长原因检查通过；浏览器控制台无错误。空列表仍显示完整内容面板。
- 使用本地演示数据；待接收、丢失的边界样例仅在浏览器响应中模拟并于检查后撤销，未写入数据库或生产库存。截图及检查脚本保存在 `output/playwright/team-single-line-20260927/`。
- 自动化 Chrome 已关闭；仅本地提交，尚未推送或部署。
