# 班组页面与录入体验核对（2026-10-09）

本次配套发布前后端。以下为近期明确提出的要求及实现范围；仓位、转料、扫码和库存归属继续使用既有业务规则。

| 要求 | 已实现 |
| --- | --- |
| 班组统计可放大全屏、固定表头 | 库存明细、来料待签收、入库记录、出库记录、丢失记录、材质库存、类型库存；保留分页，表格内部滚动 |
| 放大后减少占位内容 | 隐藏班组导航、设置、重复标题和业务创建按钮；保留搜索、筛选、查询及库存显示列，表头和分页保持可见；窄窗口查询栏自动换行 |
| 按筛选结果并选择字段导出 | 上述七个列表导出 Excel，读取全部匹配分页；字段可勾选，表头冻结，件数/重量保留数值类型 |
| 管理员修改自己和其他班组信息 | 左下角“个人信息”编辑姓名和头像；“班组长管理”维护其他班组长资料；“班组管理”修改名称、说明、业务 |
| 班组长编辑自己的信息和头像 | 个人资料允许姓名、头像；提供八款参考头像；不能修改权限或其他账号 |
| 管理员和班组长修改自己的密码 | 个人信息的“修改密码”填写旧密码、新密码及确认密码；新密码至少八位，成功后撤销本账号所有登录会话并重新登录；管理员重置班组长密码的功能保留 |
| 输入流水号提供相似记录 | 手工入库、转料表单、初始库存、流水号转投支持已有流水号下拉建议；材质、客户编号、产品编号、零件号、外部单位也可复用已有值 |
| 同流水号补充资料并明确提示 | 完整输入流水号或选择建议后补充材质、成品规格、客户/产品/零件编号、技术要求；“已带入”标记提供原单批次提示；保留手工修改，切换流水号清除未修改的自动值 |
| 弹窗字段整齐、长表单分页 | 统一字段和单位排版；转料与手工入库按资料分为七页，初始库存每批三页，批量出库每批单独填写；翻页保留所有输入 |
| 必填标记和漏填提示 | 必填字段显示红色星号；提交时跳到缺少内容的页，提示页码、页面名及具体字段；入库说明选填，交期与应发件数成对填写 |
| 常规尺寸和异形输入 | 长方体、圆柱、圆环提供分项输入与 mm 单位；异形自由填写，旧规格原文保留；未填写完整或圆环外径小于等于内径时提示 |
| 筛选集中在一个框中 | 班组库存和记录、全局转料记录、出库选料、仓位管理集中为筛选弹窗；应用才生效，取消不改变已应用条件 |
| 青色搭配突出按钮 | 青色主操作、暖色出库、蓝灰工具按钮；统一表头、间距、悬停反馈及小屏排布 |
| 每个账号最多同时登录三个 | 第四次成功登录撤销最早会话；失败登录、不同账号、过期会话和并发登录均有回归验证 |

自动补充仅用于录入便利，不设置来源批次关系，也不带入件数、重量、交期、物料类型或仓位。来源选择和仓位锁定仍通过原业务流程执行；手工输入始终可用。每个流水号只显示一个建议，资料取最新有效单据；完全匹配优先于相似号。一个流水号可关联多张独立批次单，不限制为只能生成一张转料单。

头像当前提供八款内置参考头像。查询图表中的普通搜索输入保持原查询行为，不会自动修改业务资料。

自行修改密码只操作当前登录账号，错误的旧密码不会退出登录。密码与会话撤销、审计一同提交，日志和校验响应不包含密码；并发登录会重新核对密码，避免旧密码在修改后创建新会话。管理员忘记密码仍由运维协助恢复，没有新增免验证重置入口。

新增用户字段 `avatar_key`，迁移 `20261009_0029` 为原账号补充空头像，不更改账号密码、班组绑定或历史物料。资料更新沿用事务内审计。管理员有配置权限，班组库存写入仍由相应班组账号执行。

验证记录分别位于 `output/playwright/team-statistics-fullscreen-20261009/`、`team-export-20261009/`、`account-profile-20261009/`、`input-polish-20261009/`。独立 Chrome 检查管理员、库房及普通班组长；覆盖 1920×1080 至 390×844 等八种视口，包含真实筛选、字段导出下载、资料保存、自动补充和初始库存提交。任务浏览器及临时服务已关闭。

本轮表单与全屏补充验证位于 `output/playwright/dialog-forms-20261009/` 和 `output/playwright/fullscreen-toolbar-20261009/`，覆盖九种视口，最小为 320×568，并包含 844×390 横屏。正常窗口减少单页字段，提交按钮保留在弹窗底部；极矮或极窄窗口仍允许内容区滚动，避免裁掉字段。
