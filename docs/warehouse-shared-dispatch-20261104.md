# 库房共投转出

库房入库登记实际收到的物料、件数、重量和仓位，不再新建共投关系。流水号及工艺可以在入库时关联，尚未明确的在转出前补齐。

库房原料向下序班组内部转出时，可在该批物料上选择“共投”。每个流水号独立填写计划用料重量、切出件数、切割尺寸，并关联自己的已发布工艺、订单和图纸。转出件数和重量仍按实物填写，各流水号的计划不重复计入库存；只转出一部分时，库房余料保持原记录。

多个流水号在实物拆分前须有相同班组、加工任务和业务。允许先整块经过共同工序，再由轧制、线切割或雕刻登记实际拆分。最迟在共同路线的最后一个可拆料工序完成归属，之后各产出批次使用对应流水号的工艺；未加工余料和废料保留共投关系。

历史共投入库、原有加工记录和重复提交回放保持兼容。数据库迁移 `20261104_0066` 只增加可空的工艺关联与拆料边界字段，不重写历史库存。

库存、收发等多视图模块通过页头的当前位置下拉切换，复用 `WatermelonFilter` 的动画、键盘操作和待办数量。单独的页签行移除；原“材质库存”链接回到库存明细，保留筛选参数。

验证覆盖：单次实物扣减、部分转出余量、共投重复提交、无效工艺和计划的事务回滚、共同工序后再拆料、拆分后各自工艺、历史共投兼容、数据库迁移保留旧记录，以及页头切换与表单交互。Chrome 仅检查本地界面，未提交业务记录。
