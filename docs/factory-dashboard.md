# 全厂总览（真实业务数据）

首页使用 `/api/factory-dashboard`，独立玻璃大屏 `/factory-live` 保持原样。

- **材质库存与班组分布**：动态材质列，重量/件数切换、班组和全厂合计，可下钻流水号及物料类型。所有权为可用库存加预留库存；内部待接收仍归上游，确认后移交下游。不会把预留料重新变为可出库料。历史班组只要仍有库存也纳入合计。
- **成品率**：只汇总已完结流水号，外部入库重量为投入，已确认成品外发重量为产出。按材质 → 流水号 → 班组下钻；班组按已确认合格转出或外发重量 / 本班组收料重量计算。仍有结存或待确认时显示进行中。期初、退货、未纳入库存的历史记录、缺少投入等无法直接核算的流水号显示投入待核对，不伪造最终成品率。
- **交期履约**：每条流水号可设置多个批次、交期和计划件数。确认成品发货按交期先后依次抵扣，完成日期取实际发货确认日期。交期当天结束后才判超期；按期率以已过交期批次为分母，提前完成的未来交期批次暂不计入。待确认发货不抵扣。管理入口：查看全部交付计划 → 设置交付计划。
- **发货速率**：按流水号创建时间默认最新五条，件/天，横轴为工厂当地日期。展开画布可搜索所有流水号、分页加载、选择比较、切换日期和缩放。单次最多比较 100 条、366 天；流水号创建前为空值，创建后未发货为零。画布不展示材质筛选和重复明细表。曲线约一秒逐渐绘制、每条错开 55 ms；减少动态效果偏好下关闭动画。
- **重点关注**：按流水号列出超期、加急和库龄较长的料，显示当前班组及计划欠件，可进入全链路追踪。库龄阈值七天，用当前仍持有库存最早收料日期判断。

交付计划写入仅管理员可用，使用版本号检查并发修改；计划和审计同事务提交，提交后记录操作日志并发送库存更新通知。页面通过既有 SSE 失效通知重新拉取数据，60 秒刷新作为补充；刷新失败保留上次数据并提示。没有交期计划时不推断交期，没有业务记录时展示空态，不使用示例数据填充。

数据库迁移 `20260926_0019` 仅新增 `serial_delivery_plans`，不改原有物料、库存、账号、班组记录。用户此前授权清空业务的维护工具已包含新表，但本次发布不执行清理。应用回退保留计划表；旧镜像不认识新 Alembic 修订号，需用发布目录的 rollback-compose.yml 跳过旧迁移入口，禁止为回退界面回灌整库。
