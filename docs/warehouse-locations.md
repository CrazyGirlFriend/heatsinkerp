# 库房仓位与批次占用

更新：2026-09-28。“仓库管理、单批独占及填写时锁定”已随 `20260928T063236Z` 发布，程序提交 `568284a`，迁移版本 `20260928_0023`。数据库共 34 张表，包括 33 张业务／系统表和 1 张迁移版本表。

## 使用

- 库房账号或管理员在“班组工作台 → 库房 → 仓库管理”新增、修改、停用仓位；已锁定或有料的仓位不能修改。
- 上游转料单转入库房时，每一行物料可以选一个空闲仓位；库房手工入库也可以选择。单据未选时，库房单批签收仍可补选。
- 仓位可留空。无空仓时提示“暂无空闲仓位，可不填写”。不能在单据中随意输入未建档仓位。
- 一个仓位只接受一个入库批次。每条转料明细都有独立批次号，批量提交也不能让两条明细共用仓位。
- 入库记录、批次详情及出库选料可查看仓位；仓位不会自动继承到下一班组。

## 锁定与释放

| 情况 | 仓位状态 |
| --- | --- |
| 填写时选中仓位 | 立即锁定，其他表单和账号不可再选 |
| 未提交，取消／关闭表单／清空选择 | 释放临时锁 |
| 换仓位 | 新仓位锁定成功后释放原仓位；选择失败保留原选择 |
| 未提交满 10 分钟 | 自动到期，提示重新选择；继续填写或续锁不会延长上限 |
| 断网／浏览器异常退出 | 最多 3 分钟失联到期，且不超过原 10 分钟上限 |
| 提交转料单成功，待库房签收 | 由单据占用，关闭页面不释放 |
| 库房签收／手工入库成功 | 有料，占用仓位 |
| 尚未签收的入库单作废 | 释放目标仓位 |
| 仅部分转出／全部转出但尚未全部签收 | 原仓位继续占用 |
| 件数和重量都清空，且没有待签收的转出 | 原仓位可再次选择；对外出库按确认完成计算 |

选仓位后显示“已锁定 · 09:59 后释放”，剩余 1 分钟变为橙色提醒。提交成功后临时锁转换成单据占用，不受填写倒计时影响。

既有数据不会被迁移改写：历史仓位名称会进入管理目录。如果旧仓位已有多个批次，只展示真实记录，禁止再放入新批次，直到全部清空。

## 后端约束

- `warehouse_locations` 保存仓位目录、版本号、持锁账号、表单随机键、短期有效时间和固定到期时间。
- `POST /api/warehouse-locations/{id}/reservation` 选中／续锁；`DELETE` 同一路径取消。旧表单迟到的释放请求不能清掉新表单或已提交单据的占用。
- 管理目录 `GET/POST /api/warehouse-locations`、`PATCH /api/warehouse-locations/{id}` 仅库房账号和管理员可用，修改检查版本并记录审计。
- `GET /api/team-materials/{team_id}/warehouse-locations` 仅返回可选仓位，以及当前选择用于回显的仓位。
- 入库、转料明细和补选签收同时传 `warehouse_location` 与 `warehouse_location_reservation_key`。后台在同一事务中检查持有人、有效期、单批占用并保存单据；界面判断不能绕过后端限制。
- 已提交单据的仓位不能直接更换；待签收单据需要作废重建。历史件数、重量、库存归属和批次关系保持不变。
- 发布前备份并停止旧写入服务，执行 `alembic upgrade head` 后启动新版服务；不能同时保留旧版自由输入仓位的写入节点。
