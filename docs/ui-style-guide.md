# 界面一致性约定

业务页面使用现有 Watermelon 和 Element Plus 组件。字号、字重、控件高度和圆角统一在 `frontend/src/styles/base.css` 的 `:root` 定义。桌面、窄屏和深色模式使用同一套尺度。

## 字体层级

| 用途 | 字号 | 字重 | 字号变量 |
| --- | --- | --- | --- |
| 页面标题 | 20px | 600 | `--workspace-heading-size` |
| 弹窗、抽屉标题 | 18px | 600 | `--dialog-title-size` |
| 表单分组、卡片标题 | 16px | 600 | `--font-size-section` |
| 正文、表格数据、输入值 | 14px | 400 | `--font-size-body` |
| 标准按钮 | 14px | 500 | `--font-size-body` |
| 字段标签、表头、紧凑按钮、行内操作 | 13px | 500 | `--font-size-label` |
| 辅助说明、单位、时间戳 | 12px | 400 | `--font-size-meta` |

字重依次使用 `--font-weight-regular`、`--font-weight-medium` 和 `--font-weight-semibold`。页面标题在窄屏上通过换行或省略适应宽度。登录页品牌字、图表指标和纸质单据按各自的展示尺寸排版。

## 按钮与表单

| 控件 | 高度 | 圆角 |
| --- | --- | --- |
| 工具栏、弹窗底部的标准按钮，常规输入框 | 40px · `--workspace-control-height` | 8px · `--radius-control` |
| 小按钮、分页按钮 | 32px · `--control-height-small` | 6px · `--radius-compact` |
| 表格行内文字操作 | 随行内容 | 6px · `--radius-compact` |

- 操作按钮复用 `AppButton` 或基于它的 `WatermelonButton`。普通操作用默认尺寸，紧凑操作传 `size="small"`，行内操作使用 `link`。关闭按钮沿用圆形，数量和单位组合输入仅外侧保留圆角。
- 搜索、筛选、刷新和业务操作放在 `WorkspaceDataToolbar` 对应插槽。分页复用 `WorkspacePagination`，弹窗复用 `AppDialog`。新增业务页面引用公共尺度，避免在页面或媒体查询中重新定义它们。
- 业务颜色与交互状态使用 Watermelon 主题，包括主操作、悬停、焦点、禁用和加载。页面布局使用 `App.vue` 与各工作台的共享容器。

## 列表与布局

- 班组台账、库存、收发记录、材质归类、管理列表与屏幕中的单据详情使用相同表格尺度，表头和普通内容居中；备注、原因及变更内容左对齐。勾选列缩小横向内边距，避免裁切复选框。表单、紧凑日历和打印保留自己的尺寸约束。
- 默认每页 10 条，提供 10/20/50/100 选择。普通列表随行数纵向滚动；窄屏宽表允许内部横向滚动。抽屉保留固定操作区和内部滚动。
- 同一层级的导航图标、文字起点、选中态一致；只保留一级/二级。班组使用同一工作台组件，差异通过现有班组能力显示，不复制八份页面。
- 搜索、日期、状态、操作按同一筛选区排列；空间不足换行，不裁掉按钮。权限仍由既有账号规则控制，不为视觉统一开放管理员业务操作。
- 日期使用现有 `RecordDateFilter`；加急使用现有 `SerialUrgencyBadge`。保持键盘焦点、减少动画及状态文字，不只靠颜色表达。
- 表单字段对齐；必填未填时通过输入框标红、聚焦和短暂轻震提示，不堆叠重复说明。按钮、展开收起与件数/重量变化复用共享交互，尊重系统减少动画设置。

## 展示与打印的边界

- 首页与分析：保持现有布局、图表线条及状态色，主内容使用亮白；图表浮层保留白色玻璃材质与数字变化动画，不添加无关装饰。
- 普通列表：亮白实底与共享浅色表头，不放大面积玻璃背景，不添加无关图表或重复摘要。
- 单据：使用 `MaterialDocumentTable` 与现有明细表；打印保持黑白表格、整批一个条码，不带侧栏、卡片阴影或页面背景。
- 数据分析页使用普通业务界面；独立动态大屏及全屏轮播已取消，详见 [大屏移除说明](factory-screen-removal.md)。
