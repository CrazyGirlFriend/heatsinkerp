# 界面一致性约定

2026-09-14：以用户确认的浅白紫首页为基准。适用于现有 Vue 3 / Element Plus 业务前端，不改变业务模型。

## 共用基础

- 普通页面统一使用 `App.vue` 的 `app-shell--business`，不要在某个路由上另设导航宽度或字体。桌面侧栏 200px、收起 64px、顶栏 52px；手机使用现有抽屉导航。
- 页面、表头、边线、主色和文字色从 `styles/base.css` 的变量引用；Element Plus 控件通过 `styles/element-theme.css` 适配，不再每页定义一套蓝灰/紫灰色。
- 主色 `#692ad6`；正文 `#211a32`；辅助文字 `#70647f`；页面底色 `#fcfbfe`；表头 `#eee9f4`。成功、待处理、错误仍使用绿、橙、红的状态语义，不全部染紫。
- 中文共用本地 HeatSink Han 子集及系统回退字体，首页大数字保留 Inter。新增中文文案时按 `THIRD_PARTY_NOTICES.md` 说明更新子集，不删系统回退。

## 信息密度与控件

- 业务列表采用 `reading-workspace.css` 与 `business-tables.css`：标题 22px，表格正文、表头及表内操作 16px，辅助文字 14px。表头加粗，正文行高 24px，单元格左右内边距及正文上下内边距均为 16px。常用筛选控件高 40px，不靠缩小字体把所有列硬塞进窄屏。
- 班组台账、库存、收发记录、材质归类、管理列表与屏幕中的单据详情使用相同表格尺度，表头和普通内容居中；备注、原因及变更内容左对齐。勾选列缩小横向内边距，避免裁切复选框。表单、紧凑日历和打印保留自己的尺寸约束。
- 默认每页 10 条，提供 10/20/50/100 选择。普通列表随行数纵向滚动；窄屏宽表允许内部横向滚动。抽屉保留固定操作区和内部滚动。
- 同一层级的导航图标、文字起点、选中态一致；只保留一级/二级。班组使用同一工作台组件，差异通过现有班组能力显示，不复制八份页面。
- 搜索、日期、状态、操作按同一筛选区排列；空间不足换行，不裁掉按钮。权限仍由既有账号规则控制，不为视觉统一开放管理员业务操作。
- 日期使用现有 `RecordDateFilter`；加急使用现有 `SerialUrgencyBadge`。保持键盘焦点、减少动画及状态文字，不只靠颜色表达。

## 展示与打印的边界

- 首页：保留确认过的白紫波纹浓度、八个独立设备图、玻璃卡片及数字变化动画。不得为了统一业务页而把首页再调浓或调淡。
- 普通列表：白色实底与浅紫表头，不放大面积玻璃背景，不添加无关图表或重复摘要。
- 单据：使用 `MaterialDocumentTable` 与现有明细表；打印保持黑白表格、整批一个条码，不带侧栏、卡片阴影或页面背景。
- 机器人大屏及分析大屏：属于独立展示模式，保留原背景、模型和专用字体/颜色；不套用普通列表外壳。
- 本轮不改 SSE、库存计算、转料确认、权限及后端。视觉统一不是接口或业务重构。
