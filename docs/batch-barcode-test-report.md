# 整批条码与汇总打印验收

日期：2026-09-07。范围：本地前后端及独立测试库；未部署生产服务器，未更改生产账号或数据。

## 实现范围

- 同一次出库只有一个 CK Code 128 条码。每行 TL 身份、来源流水号及历史审计保留，不重编号、不合并库存行。
- GET 整批读取全部明细；内部由下序一次接收，库房对外出库、检验发货由本班组一次确认。
- 必填整批内容版本摘要，任一明细变化后拒绝旧版本确认；全部待确认项与审计同一事务，不留半批。
- 同键及原摘要重试不重复收发；不同批次不能复用确认键。历史已确认/作废项不再修改，只处理剩余待确认项。
- 单联 A4 汇总打印，一个 CK 条码；常规批次以一张纸为目标，多行/长文字须完整续页。
