| 以前的说法 | 现在的说法 | 含义 |
| --- | --- | --- |
| 来源结存 | 当前库存 | 按收到的批次查看当前库存 |
| 材质结存 | 材质库存 | 按铜钼、钨铜等具体材质汇总 |

| 承接业务 | 本组业务／接收业务 | 班组设置中叫本组业务，转料单中指接收方要做的业务 |

| 演示快照 | 演示数据 | 用于演示，不代表实际库存 |

## 不能因改名而混淆的内容

- **当前库存**：仍属于本班组的物料。已经转出但下序尚未签收的，仍包含在内。
- **未转出库存**：尚未转出的物料，不含已转出待签收部分。
- **可转出库存**：出库时可选择的物料；废料仍按原来的去向限制处理。
- **待签收**：内部转料已发出，接收班组还没确认。**对外待确认**是库房或检验的外部出库，二者不能混写。
- 历史时间段图表中的未转出数量仍对应所选时间，不改称“当前库存”。
- 全链路右侧的正常料和废料分开显示，正常料小计明确叫“正常料合计”。
- “系统记录”不等于实物盘点结果，未知件数或重量仍显示“—”。
