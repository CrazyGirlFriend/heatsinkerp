# 转料查询索引与 MySQL 验证

日期：2026-09-06。迁移版本：`20260906_0006`。

## 实现

新增 11 项组合索引，覆盖列表时间排序、状态筛选、双方班组筛选、班组加状态筛选、物料类型，以及原单批号、客户代码、编号、材质查询。原有批次唯一索引与流水号加时间索引保留。ID 作为排序的第二关键字，保证同一时间的数据分页稳定。

搜索新增明确的 `exact` / `prefix` 方式和六个字段选择；原 `contains` 搜索默认值保留。列表与计数使用相同筛选口径，不根据关键词形状偷偷改变搜索语义。API 参数和范围见 [一期查询契约](phase-1-material-transfer.md#8-查询方式与索引)。

精确比较和不以通配符开头的 LIKE 可以使用 B-tree 范围定位，包含匹配不保证具备该条件。[MySQL 8.4 范围优化说明](https://dev.mysql.com/doc/refman/8.4/en/range-optimization.html)。排序是否能直接使用索引还受过滤条件和索引列顺序影响。[MySQL 8.4 排序优化说明](https://dev.mysql.com/doc/refman/8.4/en/order-by-optimization.html)。

- 0005 原始字段值保留，新增字段为 NULL，版本为 1，不生成虚假历史。

- 查询使用应用实际的 SQLAlchemy 模型和搜索函数，包含列表的班组 JOIN；没有使用 FORCE INDEX。

## 边界与上线

- 多字段任意位置包含查询仍可能扫描较多记录；不宣称普通索引已经解决全文搜索。
- 深页 OFFSET 仍有成本；本轮保留原分页行为，没有擅自改成无法跳页的游标分页。
- 新索引需要额外存储及写入维护成本。保留既有索引，后续可依据真实慢查询记录评估冗余索引，不在本轮无证据删除。
- `LOCK=NONE` 不意味着完全没有元数据锁。上线应备份，选择发布窗口，观察资源与锁等待；不支持在线 DDL 时本迁移会报错，不自动改为锁表复制。
- 本轮完成的是代码、隔离库迁移和执行计划验证；不等于已经发布到生产系统。
- 验证结束后已停止并自动删除临时 MySQL 容器及其可重新生成的模拟数据；生产前端、后端和数据库容器仍保持 healthy。
