# ECharts 收发与全链路画布

班组收发与管理员全链路分开进入。画布只读，不新增转料或修改库存。

- `/team-workspaces/8?tab=history&serial_no=000012`：正式班组收发入口。按接收用途、来源批次分轨；每条细线表示一个接收批次，分支表示该来源的转出、丢失、改量或作废退回，末端表示图示期末结存。支持日期筛选，件数和重量同时显示。
- `/material-trace?serial_no=000012`：管理员专用的全链路画布，入口位于“流转查询 → 全链路追踪”。页面路由和 `/api/material-trace` 均校验管理员权限，班组详情回到本班组收发，不再跳往全链路。
- `/flow-preview/team?team_id=8&serial_no=000012` 与 `/flow-preview/chain?serial_no=000012` 保留为独立预览；后者同样只允许管理员访问。全链路横轴为真实时间、纵轴为班组，只沿实际 `source_transfer_id` 连接前后批次，拆批与回流保留独立路径。
- 两个地址附加 `sample=purposes` 可查看已有 QA 数据库中 `000012` 的只读快照。明确标注“演示快照、非实时”，不请求库存接口，不允许打开同号业务单据。返回“使用业务数据”后才恢复真实查询和 SSE。

## 口径

本班组的当前结存读取库存台账；时间画布按来源批次的已提交事件增减还原，出库创建扣一次，修改只计差额，作废退回余额，下序确认不重复扣量。已转出待确认物料不属于本班组结存；未接收来料不计入流入。只有重量的废屑仍显示 0 件和实际重量，不补造件数。

日期筛选后，顶栏明确显示“当前结存”，图中末端为所选区间的期末结存，页脚显示图示截止时间。区间前接收但仍有结存的批次保留原接收信息；不同来源批次不因用途相同而合并。未登记用途保留“未分类”。

班组画布支持滚轮缩放、选择 / 平移、重播、动画开关和全屏；密集事件提供节点查找。点击事件打开实际批次详情，全屏时先退出全屏，避免详情抽屉被遮挡。实时更新保留同一画布、查询草稿和缩放范围。

全链路折线和事件点表示该批转料量，不是当前库存，不能相加作为全厂库存。画布同时显示件数与重量；明细另列该批当前结存。全链路预览不再放汇总卡片。历史未登记用途保留“未分类”；没有来源关系的批次不臆造连线。

## 全链路画布操作

- 底部悬浮工具栏集中提供选择、平移、放大、缩小、还原、动画开关、重播和全屏。当前模式使用浅灰滑动选块表示；悬停按钮可见操作名称和快捷键。
- 默认“选择批次”模式用于悬停和点击路径；切换“平移画布”后，按住鼠标拖动平移时间和班组范围，不会误开批次详情。画布内可按 `V` 切换选择、`H` 切换平移；输入框内打字不触发这些快捷键。
- 两种模式下均可滚动鼠标滚轮，以指针所在位置为中心缩放。底部时间滑块独占一行：拖动两端调整时间范围，拖动选区平移时间窗口。
- 双击画布或点击“还原”：回到完整链路。画布聚焦后，也可按 `+`、`-`、`0` 操作。
- 选择模式下悬停路径会加深线条并显示批次信息；点击事件点或折线突出该批及其真实上游、下游，打开明细；也可用“查找批次 / 查看明细”选择密集点。关闭抽屉后保留路径高亮，可通过画布右上角批次标签的关闭按钮取消。
- “重播”在当前缩放范围内重新逐段绘制折线，不还原视图；“全屏”展开当前画布，按 Esc 或“退出全屏”返回。全屏内仍可使用批次查询下拉与工具提示。关闭动画或系统启用减少动态效果时立即完成绘制，不清空画布。
- 实际查询接收库存事件推送后重新读取最新链路，保留缩放和查询草稿；按批次 ID 与图形子元素名称合并，仅新路径绘制、新数量渐入，未变化数据不重播。查看明细时暂缓刷新；切换标签页不触发整图重播。只读演示快照不订阅推送。

## 时间与状态

- 横轴是实际时间，不是工序序号或美化后的等距时间。界面使用北京时间；没有时区后缀的接口时间按后端 UTC 约定解析。
- 入库/期初库存显示记录的入库事件；班组转料显示转出和接收事件；外部出库使用对外确认时间。
- 待接收批次只标记转出事件及待接收去向，不补造接收时间。已确认但时间缺失、接收早于转出等异常会提示。
- 同一时间的多个事件只在班组行内错开，不修改横轴时间；同一秒内的测试记录可放大到毫秒查看。
- 八个固定班组全部保留，外部去向按实际记录另列，不冒充第九个生产班组。未发生业务的班组不补造路径。

## 参考与实现

- [ECharts 桑基图示例](https://echarts.apache.org/examples/en/editor.html?c=sankey-energy)：流带宽度、分流和轨迹高亮。
- [ECharts Canvas / SVG 渲染说明](https://echarts.apache.org/handbook/en/best-practices/canvas-vs-svg/)：本班组与全链路时间画布均使用 SVG 渲染，缩放保持线条和文字清晰。
- 全链路使用 ECharts custom series、双轴 inside dataZoom 和时间 slider；折线使用 `strokePercent` 逐段绘制，不使用随机力导向布局或预制视频。
- [ECharts 动画指南](https://echarts.apache.org/handbook/en/how-to/animation/transition/)：进入、更新动画与重播；遵守减少动态效果偏好。
- [Bencho 工具栏](https://bencho.dev/?c=toolbar&theme=light)与[交互曲线](https://bencho.dev/?c=pull&theme=light)：参考白色悬浮工具、浅灰选中态、细线与悬停反馈；使用现有 Element Plus 图标、Vue 与 ECharts 实现，没有复制网站应用或商业字体，也不增加绘图编辑器功能。

样例快照来自 `output/playwright/team-business-20260918/qa.sqlite3`，导出时只读连接，保留检验、去毛刺、发货三种用途，库存合计 953 件 / 119.125 kg，其中检验班组结存 153 件 / 19.125 kg。演示快照不代表线上当前库存。

图形将更多字段放在点击明细中，主区域保留流向与双单位。班组收发画布已接入正式工作台，沿用既有业务页面外壳；全链路保持独立高清画布。

本地验收：覆盖滚轮缩放、拖动平移、滑块、双击还原、全屏、批次选择与重播；核对 1366 × 768 和 2560 × 1440，未做 4K 测试。实际发布版本以 [服务器部署记录](server-deployment.md) 为准。
