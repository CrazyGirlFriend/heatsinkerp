# 生产与质量统计口径

全厂数据分析以“生产完成”“检验与质量”为主，原有库存、对外收发、交接与异常保留在“库存与交接”。支持班组、日期筛选以及选择字段导出，日期范围最多 366 天。

## 生产完成

按实际加工日期汇总，正常加工与返工分别统计完成件次、加工重量、登记笔数和废料重量。同一工件完成不同任务各记一次工作量；跨班组或跨任务的合计表示工作量，不表示全厂唯一成品产量。未加工余料、出库动作不再次计产。历史缺少明确产量或加工人的记录沿用加工日报规则，不猜测补入。

## 合格率

合格率为合格件次除以实际受检件次。巡检与检验、抽检与全检、首次检查与复检分别查看；没有检查记录显示未检查。按受检物料所在班组统计，不把问题涉及班组当作缺陷责任的数量分摊依据。

## 检验问题与反馈

检验班组账号进入“检验工作台 → 班组设置 → 检验问题”维护统一名称，可新增、改名、停用。巡检、检验和复检发现不合格时必须从启用选项中选择，可多选；补充说明可选，不能代替问题分类。其它班组和管理员不能代替检验班组长维护此清单。

记录保存问题 ID 与当时名称。改名或停用不改旧记录；停用选项仍可用于历史筛选。历史不合格记录没有分类的显示“历史未分类”。目录初始为空，须由检验班组长按实际业务设置。

一次不合格检查对应一条质量反馈，复检沿用原反馈。一个问题可以关联多个分类、多个班组，各分类及班组的问题数可交叉，总问题数按原反馈去重。问题图表包含所选日期、涉及班组和账号查看权限内的巡检与检验问题，与合格率口径单独标明。发货、返工、转料及处理结论仍由班组长手动决定。

## 数据保存

迁移 20261020_0043 仅增加问题目录及检查问题关联表，不改写原库存、转料、加工或检查记录。名称快照在关联表保存，关联字段有外键和检索索引。
