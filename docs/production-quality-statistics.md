# 生产与质量统计口径

全厂数据分析以“生产完成”“检验与质量”为主，原有库存、对外收发、交接与异常保留在“库存与交接”。支持班组、日期、流水号或材质筛选以及选择字段导出，日期范围最多 366 天。

2026-10-20 后续修订：本轮按流水号、任务和材质调整统计，开发与隔离检查完成后另行记录发布状态；此段不表示已部署。

## 生产完成

加工量按班组、流水号、材质、业务和具体任务分别查看。默认展示筛选范围内最近有有效加工记录的流水号和任务，不显示全厂总加工量或跨流水号的产能排名。输入完整流水号可查询，切换任务查看对应的完成量与日、周、月趋势；没有匹配记录显示无数据，不回退到其它流水号。

正常加工与返工分别统计完成件次、加工重量和登记笔数。同一工件完成粗磨、精磨分别计入对应任务，不将两道任务相加作为该流水号成品数量。共投加工以已保存的实际产出明细归属流水号：同一次加工同流水号的多个产出行先合并；未加工余料、废料和计划分配不计入完成量，出库不重复计产。历史缺少实际产量、人员或加工日期的记录不猜测补入。共投废料的分摊未确认，不在该页强行按流水号分摊废料重量。

## 合格率

统一使用“合格率”名称，按材质分别展示。合格率为合格件次除以实际受检件次，不显示把不同材质混在一起的总合格率。巡检与检验、抽检与全检、首次检查与复检分别查看；没有检查记录显示未检查。按受检物料所在班组统计，不把问题涉及班组当作缺陷责任的数量分摊依据。

## 日、周、月

加工按实际加工日期、检验按工厂时区中的实际检查日期分组。周一至周日为一周，自然月按年月区分，跨年周使用该周周一日期。周、月合格率使用周期内合格件次之和除以受检件次之和，不平均每日百分比；抽检、全检及首次检查、复检不混合计算。筛选范围未覆盖整周或整月时只统计范围内记录，导出同时保留周期起始、筛选开始与结束日期。

## 检验问题与反馈

检验班组账号进入“检验工作台 → 班组设置 → 检验问题”维护统一名称，可新增、改名、停用。巡检、检验和复检发现不合格时必须从启用选项中选择，可多选；补充说明可选，不能代替问题分类。其它班组和管理员不能代替检验班组长维护此清单。

记录保存问题 ID 与当时名称。改名或停用不改旧记录；停用选项仍可用于历史筛选。图表按问题 ID 汇总并使用当前名称，明细和记录导出保留当时名称。历史不合格记录没有分类的显示“历史未分类”。目录初始为空，须由检验班组长按实际业务设置。

一次不合格检查对应一条质量反馈，复检沿用原反馈。一个问题可以关联多个分类、多个班组，各分类及班组的问题数可交叉，总问题数按原反馈去重。问题图表包含所选日期、涉及班组和账号查看权限内的巡检与检验问题，与合格率口径单独标明。发货、返工、转料及处理结论仍由班组长手动决定。
